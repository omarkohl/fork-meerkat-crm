# 0013. Vite builds the frontend

- Status: Accepted
- Date: 2026-10-17

## Context

Create React App (`react-scripts` 5) is deprecated and gets no fixes. It pulls in webpack, Babel, Jest and ESLint 8 (thousands of lockfile lines and their CVEs), and its build took over a minute. Vitest already used Vite.

## Decision

Vite builds and serves the frontend. One `frontend/vite.config.ts` holds the build, dev server and Vitest settings. The output stays in `frontend/build/`; hashed files are under `build/assets/`. Build-time variables use the `VITE_` prefix (`VITE_API_URL`, `VITE_REQUEST_TIMEOUT`) and are read through `import.meta.env`. The unused CRA service worker and web-vitals code are removed.

## Consequences

The build takes seconds and the dependency tree is much smaller. Self-built images and local `.env` files must rename `REACT_APP_*` to `VITE_*`. The nginx cache rule for hashed files matches `/assets/`.

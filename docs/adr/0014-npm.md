# 0014. npm manages frontend dependencies

- Status: Accepted
- Date: 2026-10-17

## Context

Yarn 1 is in maintenance mode. Node 25 and later do not include Corepack, so Yarn had to be installed globally in every Docker image, CI job and developer machine. pnpm and Bun need the same extra step; only npm comes with Node.

## Decision

npm manages the frontend dependencies with `frontend/package-lock.json`. Installs use `npm ci`. Dependency install scripts run only when `allowScripts` in `frontend/package.json` allows them; `esbuild` is denied, because its platform binary comes from an optional dependency.

## Consequences

Node.js is the only frontend prerequisite (one less tool, see [ADR 0004](0004-sqlite-and-few-moving-parts.md)). npm is slower than pnpm or Bun, which does not matter at this size. A new dependency with an install script needs an `npm install-scripts approve` or `deny` decision.
